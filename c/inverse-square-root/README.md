# Inverse square root

Petit projet de 3° année de licence, concernant la problèmatique de la précision de calculs compliqués, telle
la racine carrée d'un nombre. Une technique consiste à passer par la valeur inverse d'abord, pour laquelle il existe
des algorithmes performants, notamment la méthode de Newton.

Je vous invite à lire le document si cette méthode vous intéresse, car elle n'est pas évidente à exposer sans
notations mathématiques. Le programme implèmente cette méthode et la compare en terme de précision avec celle de la
bibliothèque C.

`CMake` et `Gnuplot` sont requis pour faire fonctionner le script `run.sh`.
