# N-queens

Le problème des n-reines est assez simple à énoncer, il s'agit de prendre un échiquer de _n x n_ cases et d'y
placer _n_ reines de manière à ce qu'aucune ne soit en prise d'une autre (selon les règles des échecs).

Dans le cas de ce projet de 3e année de licence, il s'agissait surtout d'un prétexte pour nous faire étudier
différentes manières de résoudre le problème, notamment en utilisant des algorithmes déterministes et d'autres
aléatoires, ainsi qu'un petit mélange des deux.
