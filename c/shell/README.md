# Shell

Comme exercice de programmation système, le développement d'un mini-shell est vraiment classique. L'idée est de
refaire les fonctionnalités de base du shell UNIX, à savoir le lancement de commande, le changement de dossier, la
possibilité de faire des redirections vers des fichiers ou vers d'autres programmes, ou encore le lancement de
commande en fond de tâche.

En L3, je me souviens d'avoir eu à faire cela, mais le code résultant était vraiment tout pourri. Aussi ai-je
entrepris de recommencer ce programme, en essayant de faire un code plus clair et commenté. J'espère y être arrivé..
