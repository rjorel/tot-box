# Sorts

Lors de ma 3ème année de licence, j'ai eu à faire un travail d'études bibliographiques sur les
tris, avec [Stanislas Pagès](https://www.linkedin.com/in/stanislas-pag%C3%A8s-1285aa150/). Comme il
nous est apparu pendant cette étude que les ressources françaises sur le sujet étaient peu nombreuses, j'ai voulu
publier notre rapport sur un site, ce qui m'a amené à développer la première version de mon site personnel.

Les algorithmes en source sont légèrement différents de ceux présentés dans le rapport car je les ai repris pour les
clarifier un peu, et rendre le programme centré sur l'exécution des algorithmes plutôt que de lui faire faire des
mesures de performances, comme fait au départ pour les besoins du projet.
