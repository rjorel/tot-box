# RPN evaluator

La notation polonaise inversée (Reverse Polish Notation) est une notation d'expressions mathématiques très facile à
évaluer, car l'ordre des opérations est donné par le placement des opérateurs dans les expressions. Vous pouvez
trouver une explication détaillée sur [Wikipédia](https://fr.wikipedia.org/wiki/Notation_polonaise_inverse).

Ce programme est proposé comme exercice dans le célébre livre _The C Programming Language_, de B. W. Kernighan
et D. M. Ritchie, mais j'ai préféré le faire en C++ car le modèle orienté objet me manquait trop.

Le programme s'utilise en console et l'expression à évaluer doit être donnée en ligne de commande.
