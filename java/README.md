# Java

Ah Java Java, on entend parler beaucoup de lui.. même les gens qui n'y connaissent rien en ont entendu parler, c'est
dire. En même temps, c'est assez logique à cause des mises à jour sur Windows demandées explicitement (qui
installent Ask en passant si l'on ne fait pas gaffe).

Pendant un moment, je n'ai pas aimé ce langage. Je lui reprochais ce que la plupart des développeurs lui reproche..
sa verbosité, sa lenteur (cela s'est bien amélioré), sa rugosité, etc.. j'utilisais principalement Eclipse à cette
époque, puis un jour j'ai découvert [IntelliJ](https://www.jetbrains.com/idea/). Et

> Voici, toutes choses sont devenues nouvelles

(2 Corinthiens 5:17 ; une petite citation de la Bible ça claque non ?).

Plus sérieusement, cet IDE est excellent et aujourd'hui je me trouve bien moins rétif à ce langage.. même si je
m'en sers finalement très peu.
