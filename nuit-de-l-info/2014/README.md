# 2015

Cette année-là, le thème était autour de l'aide humanitaire. Mon équipe avait décidé de participer, en partie, au
défi nommé "Konami Code", où le but était de cacher plein de petits <i>easter eggs</i> sur le site web qui nous
servirait de support pour répondre au thème.

Ma participation fut de coder ce petit jeu très simple. Pour les besoins du site, nous avions inventé un pays et une
maladie qui poussaient les aides humanitaires à venir. Il s'agissait d'une maladie qui bouffait les muscles - rien
que ça -, et le jeu consiste à cliquer le plus rapidement sur un bouton pour contaminer le plus de personnes
possibles.

Il y avait bien évidemment pas mal d'autres trucs un peu décon' développés par les personnes de mon équipe. Nous
avions aussi participé à d'autres défis, mais le seul où nous avons été classé fut celui-là (3e sur une 120aine
d'équipes qui s'y étaient inscrites, si ma mémoire est bonne).
