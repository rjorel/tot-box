# REST

Les serveurs RESTful sont de plus en plus en vogue, notamment grâce aux _frameworks_ JavaScript tels Angular ou
React (pour ne citer qu'eux, sinon la liste risque d'être longue). Il est donc courant maintenant de voir les
applications web découpées en deux parties : l'application en elle-même qui s'exécute sur le navigateur du client,
et le serveur RESTful qui attend les requêtes de cette dernière.

Comme je suis particulièrement fan de PHP - et encore, le mot est faible 😀 -, j'ai fait cet exemple de serveur
RESTful avec ce langage. Je me suis pas mal inspiré de [Laravel](https://laravel.com/) pour ce petit projet.
