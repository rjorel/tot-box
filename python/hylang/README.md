# Hylang

Hylang est un savant mélange entre LISP et Python. Comme j'ai été intrigué par LISP après ma première année de
Master, Hylang s'est présenté par la suite quelque chose de fort intéressant pour moi.

La syntaxe est celle de LISP, mais la bibliothèque standard est celle de Python. De plus, des ponts sont possibles
entre Hylang et Python.

Pour essayer quelque chose de simple, j'ai traduit un exemple de serveur basique écrit en Python. On retrouve, même
avec ce programme très simple, toute l'élégance du langage LISP.
