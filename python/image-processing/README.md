# Image processing

Voici un petit programme qui synthétise quelques traitements d'image de base que j'ai pu voir pendant mon cursus,
implémentés avec Numpy.

Les algorithmes sont :
* Conversion en noir et blanc.
* Floutage.
* Augmentation / diminution de la luminosité.
* Augmentation / diminution du contraste.
* [Gradient](https://en.wikipedia.org/wiki/Gradient).
* Conversion en niveaux de gris (avec ou sans pondération des canaux de couleurs).
* [Méthode d'Otsu](https://en.wikipedia.org/wiki/Otsu%27s_method).
* [Posterisation](https://en.wikipedia.org/wiki/Posterization).
* Redimensionnement.
* Rotation.
