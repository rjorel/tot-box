# Legacy

Je laisse ici une série de vieux programmes que j'ai développés durant mes études principalement. Plusieurs
"époques" de ma vie de développeur cohabitent en ces bas-fonds..

Pygame est une bibliothèque Python qui permet de développer des jeux vidéos, c'est un _binding_ de la SDL de C,
pour ceux qui connaissent. Je l'ai utilisée principalement au cours de ma première année de licence, alors que je
découvrais la programmation, j'ai donc surtout reproduit des vieux jeux pour me former.

Tkinter est la bibliothèque de base pour faire des interfaces graphiques avec Python. De ce fait, elle est
intéressante car elle est souvent livrée dans la bibliothèque standard du langage. Le seul truc dommage, c'est
qu'elle est un peu moche.. et pas si simple à manipuler. Je l'ai quand même essayée en réécrivant certains
programmes que j'avais fait avec Pygame, et quelques autres que j'ai tirés d'exercices de bouquins.

PyQt est un _binding_ Python de Qt. Comme j'avais touché à Qt quand j'ai abordé les interfaces graphiques
en C++, j'ai eu envie de m'en servir aussi en Python.
