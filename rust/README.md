# Rust

Considéré comme THE remplaçant du C, il est difficile de passer à côté de ce langage aujourd'hui. Plus sûr au
niveau de la gestion mémoire, il ne fait (presque) aucun doute que bon nombre des failles trouvées sur des SE comme
Linux n'auraient pas eu lieu avec Rust !

Je suis souvent assez réservé concernant les langages qui sont avancés comme des "remplaçants du C", mais force est
de constater que Rust commence à faire son trou. Au point que le noyau Linux propose le support du langage, pour
l'écriture de pilotes notamment, mais surement pour d'autres composants aussi.

Je m'y suis donc essayé, mais Rust est compliqué avec beaucoup de concepts et d'éléments de syntaxe, qui le rendent
un peu difficile d'accès. Intéressant donc, mais n'y voyant aucun apport pour mon taf ou mes devs personnels, je
n'ai pas poursuivi son étude longtemps.
