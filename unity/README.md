#  Unity

Je ne connais pas beaucoup ce moteur de jeu, mais de ce que j'en ai compris après quelques recherches, c'est que
l'Unreal Engine produit de meilleurs graphismes que lui. Alors pourquoi avoir choisi ce moteur de jeu ? Eh bien, il
semblait aussi qu'Unity3D était montré comme plus intuitif et donc plus accessible à un néophyte.

De plus, ce moteur produit des jeux tournant sur un nombre important de plateformes en plus de proposer maintenant
l'éditeur sous Linux, bien que je dois avouer que la version Windows est moins buggée.

Dans le jeu vidéo, Linux a toujours un temps de retard.. c'est bien dommage.
